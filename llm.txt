# PromptHub — project context for LLM assistants

> Self-contained project snapshot for external tools and AI assistants. Keep this file brief and current.
>
> Last updated: 2026-10-29

## What this project is

PromptHub is a local MCP router for macOS. It exposes a single local endpoint on localhost:9090 and centralizes:

- MCP server lifecycle and routing
- per-client enhancement and privacy controls
- OpenAI-compatible `/v1` access to local models
- circuit breakers, caching, and audit/logging

This is an app-level router and enhancement layer, not a tracked per-client config repo.

## Stack and runtime

- Python 3.11+ with FastAPI, Pydantic, httpx, SQLAlchemy/SQLite patterns
- Node.js bridge in `mcps/prompthub-bridge.js`
- Local model backend: LM Studio or a compatible OpenAI-style local endpoint
- Dashboard at `/dashboard`
- State under `~/.prompthub/` by default

## Current model usage

- Default enhancement model: `qwen3-4b-instruct-2507`
- Orchestrator/reasoning model: `qwen3-4b-thinking-2507`
- Local health-monitoring/tool-compression workflows may also use `qwen-3.8b-distill` as a separate runtime model

Exact runtime IDs matter more than family labels. Use them verbatim in config and examples.

## Important repo conventions

- Machine-local client configs live outside the repo; they are not maintained as a tracked `clients/` tree.
- The repo source of truth for router behavior is under `app/configs/`.
- `enhancement-rules.json` holds per-client enhancement settings, privacy levels, and `model_profile` / `tool_profile` mappings.
- `model_profile` is a real feature and is not a stale concept.

## Key design choices

- Privacy boundary is enforced by `PrivacyLevel` (`local_only`, `free_ok`, `any`).
- Local-only clients do not leak prompts to cloud providers.
- Enhancement is optional per client and fails gracefully when the local model backend is unavailable.
- Tool schema minification reduces context size before sending tool definitions to clients.
- The router supports an OpenAI-compatible API and a local MCP gateway.
